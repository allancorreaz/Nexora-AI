# Nexora AI

Plataforma inteligente de conhecimento e assistência corporativa.

## Sobre o projeto

O Nexora AI é uma aplicação web que utiliza inteligência artificial e RAG (Retrieval-Augmented Generation) para transformar documentos, treinamentos e procedimentos em conhecimento acessível por meio de conversas em linguagem natural.

## Tecnologias planejadas

- Next.js e TypeScript
- Python e FastAPI
- PostgreSQL e pgvector
- Inteligência Artificial e RAG
- Docker
